# Assets

Type: reference · Audience: developers · Status: Phase F1-F5a active + planned Phase F5b-F7 assets
Verified against: Phase F5a build, ELF & VPK verification (2026-11-22)

How assets enter the FireRed Vita build today, why the `0005-port-hooks.patch` (`PORT_BRIDGE`)
external-asset layer can become zero-cost `static inline` identity helpers without breaking upstream
patches, and how Kanto 3D voxel data (`Phase F5a`) and the Native 16:9 UI atlas (`Phase F7`) are
generated.

## 1. Linked game data (INCBIN model)

This repository does not ship copyrighted game graphics, audio, or binary data. Before the first
build from a fresh clone, `fetch_assets.sh` (invoked automatically by `build_all.bat` /
`build_all.sh`) verifies a dump of the user's own Pokémon FireRed `.gba` cartridge locally, downloads
the upstream `pret/pokefirered` media listed in `tools/assets/manifest.txt`, and verifies every file
hash. Unlike `Pokemon-FireRed-3DS` (which streams ROM assets from an external `romfs:` `.pak`), the
Vita build embeds all game assets from `graphics/`, `sound/`, `data/`, and `src/data/` directly
into the ELF:

- `vita/assets.mk` converts raw decompilation media into `.4bpp`, `.8bpp`, `.gbapal`, `.lz`, `.bin`,
  and `.s` outputs using the pret host tools in `tools/` plus `charmap.txt` and the 6 upstream rule
  makefiles (`graphics_file_rules.mk`, `tileset_rules.mk`, `map_data_rules.mk`,
  `spritesheet_rules.mk`, `json_data_rules.mk`, `audio_rules.mk` — restored in Phase F1 alongside
  the 6 missing `asm/` macro include files for `data/*.s` preprocessing).
- `tools/preproc/preproc` compiles `.s` and `.c` `INCBIN_*` references.
- CMake links `generated/game_data.o` (with `.rodata` renamed `.data` via `arm-vita-eabi-objcopy`
  so relocatable pointers in `maps.s`, `event_scripts.s`, and `sound_data.s` reside in `RW` memory)
  into the final `pokefirered` ELF alongside `game_combined.o`.

Because all `INCBIN` symbols are resident in virtual memory, Phase F2a converted the 36 no-op and
identity stubs (`Port_Resolve*`, `Port_Asset*`, `Port_LoadAsset*`, `Port_Prof*`, etc.) from
`src/platform/vita/fr_vita_bridge.c` into **`static inline` identity helpers** in
`src/platform/compat/port_platform.h` and `src/platform/compat/port_prof.h` under `#ifdef PLATFORM_VITA`,
keeping the 101 `#ifdef PORT_BRIDGE` sites across 71 `src/*.c` files intact for clean merges
with future `Pokemon-FireRed-3DS` updates.

## 2. Host tools (`tools/`)

Prebuilt Windows binaries and sources currently present in `tools/` include:
- `tools/preproc/` (`preproc`)
- `tools/scaninc/` (`scaninc`)
- `tools/ramscrgen/` (`ramscrgen`)
- `tools/rsfont/` (`rsfont`)
- `tools/wav2agb/` (`wav2agb`)
- `tools/bin2c/` (`bin2c`)
- `tools/gbafix/` (`gbafix`)
- `tools/dev/` holds the Vita crash decoder (`tools/dev/addr2line_vita.sh`) and upstream
  patch-sync helper (`tools/dev/sync_fr3ds.py`). Legacy 3DS/Azahar helpers were removed in Phase F1.

`make_tools.mk`, phase-aware `tools/core_boundary/`, `tools/doc_check/`, and `tools/version/` were
added in Phase F1; `tools/ui2/` is scheduled for Phase F7.

## 3. Port data (`assets/` -> `app0:` in Phases F5–F7)

Stage 1 UI icons (`src/platform/fr3ds/fr_ui_icons.h`) are compiled directly into the ELF alongside
`vita/sce_sys/` (`icon0.png`, `pic0.png`, `livearea/contents/`). Starting in Phase F5a, `CMakeLists.txt`
also packages Kanto 3D voxel binaries from `assets/voxel/` (generated by `voxelgen/regen.sh` from
`voxelgen/scripts/`) into `pokefirered.vpk` under `app0:voxel/`:

| Target File | Packed as | Read by | Format & Content | Generator |
|---|---|---|---|---|
| `assets/voxel/buildings.bin` | `app0:voxel/` (`F5a` active) | `voxel_building.c` | Kanto & Sevii 3D `VXB7` buildings (`46` pages, `129` models, `235` placements) | `Pokemon-FireRed-3DS` `fr_gen_buildings.py` + `fr_building_specs.py` + `fr_art.py` (`640` primary metatile split) |
| `assets/voxel/relief.bin` | `app0:voxel/` (`F5a` active) | `voxel_relief.c` | Kanto cliffs, plateaus, Mt. Moon / Rock Tunnel / Seafoam / Cerulean Cave / Victory Road faces (`143` layouts) | `Pokemon-FireRed-3DS` `fr_gen_relief.py` + `relief_fixes.json` |
| `assets/voxel/trees.rgba5551` | `app0:voxel/` (`F5a` active) | `voxel_renderer.c`, `voxel_tree.c`, `voxel_room.c` | `512x1024` Morton-swizzled Kanto props/trees and 3D room wall/furniture art | `Pokemon-FireRed-3DS` `fr_gen_trees.py` + `fr_gen_rooms.py` (also emits `voxel_room_table.h` & `voxel_props_table.h`) |
